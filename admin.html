League fee

Every player pays this once a season. It all goes into The Last Draw prize pot, and a player’s points only count once it’s paid. Changing the season name in League settings starts everyone as unpaid again. Set it to £0 to switch it off.

    Season report

    An Excel file of the year to keep on file: the league table, every result, every event, each player’s totals (spent, won, up or down) and league fees. Night reports for single events are on the Results tab.

    Backup

    Saves all the league’s data to one file on this device: players, events, replies and payments, results, re-buys, seating, settings, payout tables, messages and the photo list. Keep it somewhere safe, like your email or cloud drive. It doesn’t include the photos themselves or the invite code.

    Test players

    Dummy players for trying things out. They can’t log in, and they show with a 🧪 in front of their name. Delete them all before the season starts.

    Payout tables

    Only admins can see these. Each row is the percentage of the prize pool for 1st, 2nd, 3rd… and must add up to 100. Players only see the amounts.

    How points work

    Score = √(n × b² ÷ e) ÷ (f + 1)

    n = players in the event · b = event buy-in · e = what the player spent (buy-in + rebuys + add-ons) · f = finishing position. Plus the knockout bonus above for each knockout.
